# military-ranks

Тренажёр воинских званий Российской Федерации.

## Как добавить погон

1. Положите изображение в папку `public/ranks/russia/army`.
2. Откройте `public/ranks/russia/army/catalog.json`. Скопируйте одну запись в список, отделите её запятой от соседней и замените имя файла и звание. Например:

   ```json
   {
     "photo": "major-field.webp",
     "rank": "Майор"
   }
   ```

3. Проверьте имя файла вместе с расширением. Если у звания несколько изображений, добавьте по записи для каждого и пишите звание одинаково.

Тренажёр выбирает фотографию и перемешивает правильный ответ с тремя другими званиями из каталога. Для четырёх вариантов в каталоге нужны как минимум четыре разных звания. После изменения каталога пересоберите и опубликуйте сайт.

## Как подключить флот

Для флота уже подготовлен отдельный каталог `public/ranks/russia/navy/catalog.json`. Положите в эту же папку фотографии корабельных погон. Записи имеют тот же формат, например:

```json
[
  { "photo": "matros.webp", "rank": "Матрос" }
]
```

Это пример одной записи. Добавьте изображения хотя бы для четырёх разных корабельных званий и пересоберите сайт. Карточка флота автоматически откроет тренировку. Вопросы и варианты ответов берутся только из каталога выбранного вида войск.
